# 1. Record Architecture Decisions

Date: 2026-07-29

## Status

Accepted

## Context

We need a structured way to record architectural decisions made during the design and evolution of Ferronote so future developers and AI agents understand the rationale behind core design choices.

## Decision

We will use Architecture Decision Records (ADRs) stored in `docs/adr/` using MADR-style Markdown templates.

## Consequences

- Architectural context and trade-offs are documented alongside code.
- Rationales behind key decisions are preserved.
